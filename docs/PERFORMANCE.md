## 변경 내용

- 기존 전체 게시물 JSON 읽기/파싱/정렬 후 잘라내기에서 SQL 필터·정렬·LIMIT/OFFSET으로 변경했습니다.
- 공지 목록은 제목, 링크, 날짜, 중요 여부, 첨부 개수만 최대 10건 조회합니다. 본문과 첨부 객체는 전송하지 않습니다.
- 학술활동·출판 목록과 메인 카드도 개수를 제한하고 본문은 600자, 사진은 첫 이미지만 조회합니다.
- 공개 상태/분류/정렬과 상세 slug 조회에 맞는 D1 인덱스를 추가했습니다. 상세 페이지는 전체 목록 대신 글 한 건을 조회합니다.
- 날짜 포매터는 항목마다 만들지 않고 재사용합니다.
- 공지·연구소 소개·연구진 소개는 빌드 때 HTML/RSC를 생성합니다. 운영 요청에서는 React SSR을 로드하지 않고 정적 자산을 제공합니다.
- 공지 목록 API도 가벼운 진입점에서 D1만 조회합니다. 데이터 응답을 캐시하지 않아 공개/비공개 전환 후 다음 조회에 반영됩니다. 관리자 세션·초안·첨부파일은 공개 캐시에 넣지 않습니다.

8개 Playwright 검증 통과. 로컬 Workers에서 정적 HTML/RSC, 클라이언트 메뉴 이동, 목록 API 필드 제한, 모바일 표시 확인. 운영 사이트에서 관리자 로그인·초안 작성·첨부 접근 제한·삭제 및 사진 접근 확인.

D1/R2 바인딩, 데이터베이스 ID, 미디어 버킷을 유지했습니다. 새 Worker나 유료 플랜, 자동 업로드/백업 작업은 생성하지 않았습니다.
