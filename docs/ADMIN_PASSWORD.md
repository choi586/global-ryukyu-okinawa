# 관리자 비밀번호 변경

관리자 로그인 → 관리 메뉴의 **비밀번호 변경** → 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인 입력 → 변경하기.
새 비밀번호는 12~256자입니다. 변경 후 모든 기기의 기존 세션이 무효화되며 새 비밀번호로 다시 로그인합니다. Pages와 Worker 주소는 동일한 관리자 비밀번호를 사용합니다.

## 저장 및 호환성

- 최초 비밀번호는 기존 Worker secret `ADMIN_PASSWORD_HASH`를 사용합니다.
- 사용자가 처음 변경하면 기존 D1 `records`의 namespace `admin-auth`, id `password`에 salted scrypt 해시와 revision만 저장합니다. 비밀번호 평문은 저장하거나 기록하지 않습니다.
- 이후에는 D1의 해시가 우선입니다. 일반 코드 배포로 비밀번호가 되돌아가지 않습니다.
- 세션은 검증된 해시의 digest에 연결됩니다. 변경 직전에 시작된 로그인도 이전 버전 세션으로 처리되어 새 비밀번호 변경 후 권한을 얻지 못합니다.
- 동시 변경은 revision 조건으로 원자적으로 보호합니다. 관리자 인증, 동일 출처 확인, 현재 비밀번호 확인, 시도 제한, 요청 크기 제한을 적용합니다.
- 일반 게시물 내보내기는 notices/carousel만 포함하므로 관리자 인증 레코드는 내보내지 않습니다.
- 이 기능 배포 자체는 운영 비밀번호를 변경하지 않습니다. 로컬 테스트에서만 비밀번호를 변경하고 복원합니다.

## 비밀번호 분실 시

관리자 화면에서 현재 비밀번호 없이 재설정하는 기능은 없습니다. Cloudflare 계정 소유자가 확인된 상황에서만 별도 복구합니다. D1에 변경된 비밀번호가 있으면 Worker secret만 바꿔서는 적용되지 않으므로 인증 레코드를 함께 처리해야 합니다. D1 전체 초기화 또는 다른 게시물 삭제는 필요하지 않습니다.
