# 출범식 축사

- 공개 페이지: `/launch`, `/ja/launch`. 메인 및 연구사업에서 연결.
- 관리자: `/admin/greetings`. PDF/유튜브 등록, 공개 여부, 순서, 교체·삭제.
- PDF 원본과 선택적인 첫 페이지 미리보기, 안내 포스터는 기존 R2 Standard에 저장.
- 목록은 기존 D1 `records`의 `greetings/launch`에 revision 기반으로 저장.
- 기존 관리자 세션 및 같은 출처 검증, 파일당/신규 파일 합계 3MiB, 전체 저장량 5GB 제한 적용.
- 전체 목록은 30개까지. 동시에 수정한 경우 409로 덮어쓰기 차단.
- 공개 데이터와 파일만 경량 Worker 경로로 제공. 비공개 파일은 관리자 세션 확인.
- 공개 페이지는 정적 HTML/RSC + 클라이언트 데이터 조회로 관리자 저장 후 즉시 갱신.
- 유튜브는 검증된 영상 ID만 사용하며 사용자가 클릭한 뒤 privacy-enhanced iframe을 생성. 자동재생 없음.
- 기관명·성함과 PDF 원문은 제공 자료 그대로 유지. 일본어 페이지는 안내 UI만 번역.

초기 등록 자료는 로컬 `.data/launch-upload`에 준비. 개인정보·관리자 인증자료 및 제공 PDF를 Git에 포함하지 않음.

메인 배너는 HTML/CSS `LaunchBanner` 컴포넌트. 관리자 축사 관리 상단에서 사업명·행사명·날짜·시간·장소·내부 링크를 편집하며 `greetings/launch.banner`에 저장. 기존 레코드에 banner가 없으면 기존 행사 정보로 표시.
