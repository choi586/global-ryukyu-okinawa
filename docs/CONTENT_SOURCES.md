# 콘텐츠 및 디자인 출처

확인일: 2026-09-17

## 기관 정보

- 연구소 소개 원문: https://ccs.khu.ac.kr/laboratory/okinawa
- 로고: 사용자가 제공한 `연구소로고.png`. 원본 파일은 수정하지 않고 복사하여 사용.
- 영문 명칭: 제공 로고에 기재된 `Global Institute for Ryukyu and Okinawa Studies`.

메인 소개는 원문의 인문학 기반 지역학 지향과 국제 연구 네트워크에 관한 설명을 요약했다. 비전 5개 항목도 원문에 있는 계획과 지향을 요약했으며, 이미 달성한 실적으로 표현하지 않았다. 짧은 인용문은 본문에서 인용부호로 구분했다.

원문의 하단 연락처는 비교문화연구소의 공용 연락처이므로 이 연구소의 연락처로 전용하지 않았다. 원문에 없는 설립연도, 연구실적 수치, 행사, 연구분야, 연구진, 주소를 만들지 않았다. 이전 시안의 임시 슬로건과 임의의 연구분야는 제거했다.

원문 본문에 남아 있는 ‘연구센터’ 표기 대신 사용자가 제공한 최신 로고의 ‘연구소’를 기관명으로 사용했다. 본문은 그대로 긴 인용을 하는 대신 요약하고 출처 링크를 표시했다.

## 디자인 참고

- 경희대학교 메인: https://www.khu.ac.kr/kor/user/main/view.do
- 공식 스타일 확인: `/resources/user/_common/_css/base.css`, `common.css`, `_fonts_renew/fonts.css`.
- 확인한 서체 구성: 영문 Roboto, 한글 `notokr`(Noto Sans KR), 영문 제목 Merriweather.
- 참고 요소: 붉은 상단 띠, 흰색 메뉴 영역, 넓은 콘텐츠 폭, 굵은 한글 메뉴, 영문 세리프 섹션 제목, 절제된 금색 강조.

폰트는 Fontsource 패키지로 자체 제공한다. 라이선스는 각 패키지의 LICENSE 파일에 포함되어 있다. 경희대 홈페이지의 소스코드, 대학 홍보 문구, 배너 사진은 복제하지 않았다.

사용자 요청에 따라 공개 화면의 연구소 소개 아래 CCS 이동 링크는 제거했다. 원문 URL과 확인 근거는 이 문서에 유지한다.

## 티스토리 자료 이전 (2026-09-17)

원본: https://ryukyuokinawa2.tistory.com/

공개 글 36건을 확인해 기존 소개 글 1건은 별도 중복 등록하지 않았다. 기존 연구과제 선정 공지와 동일한 글 35번은 기존 게시일·본문·주소를 유지하면서 사진 2장을 합쳤다. 최종 공개 게시물은 NEWS 2건, ACTIVITIES 22건, PUBLICATIONS 11건이다.

이전한 사진은 66장, PDF는 8개다. 사진 본문용 용량은 54,713,346바이트에서 8,921,660바이트로 약 83.7% 줄였다. 별도 640px 미리보기 66개를 생성했으며 원본은 로컬 자료창고에 보관했다. PDF는 원본 바이트를 유지한다. 제목·본문·게시일은 블로그에서 추출했으며 행사일·발행일은 제목에 명시된 날짜만 구조화했다. 외부 링크의 자동 미리보기 문구는 행사 설명에서 제외했다.

글 31번·20번은 행사 내용에 따라 ACTIVITIES로, 37번 언론 보도는 NEWS로 재분류했다. 일본학논집·연구출판·연재는 PUBLICATIONS로 배치했다. 출처 URL은 내부 데이터에 보존하되 별도의 출처 안내 문구는 공개 화면에 추가하지 않았다.
