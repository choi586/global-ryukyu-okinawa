# 글로벌류큐·오키나와연구소 홈페이지

공식 홈페이지 구축을 위한 개발·테스트 저장소입니다.

## 현재 상태

기획 확정 및 저장소 준비 단계입니다. 홈페이지 코드와 테스트 배포는 아직 준비되지 않았습니다.

## 1차 개발 범위

- 메인화면
- 공지사항 목록·상세
- 관리자 로그인 및 공지 등록·수정·삭제
- 이미지·첨부파일 업로드
- 그 외 메뉴는 ‘준비 중’으로 표시하고 비활성화

상세 요구사항은 [개발기획서](docs/PROJECT_SPEC.md)를 참고하세요.

## 개발·운영 방향

- Next.js App Router, TypeScript, React, Tailwind CSS
- GitHub에서 코드 및 변경 이력 관리
- Vercel에서 테스트 배포 예정
- 관리자 인증, DB 및 파일 저장소는 구현 시 선정
- 학교 서버 환경 확인 후 이전 방식 결정

관리자는 홈페이지의 관리자 화면에서 공지사항을 갱신합니다. 게시물과 첨부파일은 GitHub가 아닌 DB와 파일 저장소에 보관합니다.

## 저장소 구조

- `docs/PROJECT_SPEC.md`: 확정된 1차 개발기획서
- `.gitignore`: 비밀키, 로컬 설정, 생성 파일 제외 규칙

실행·관리자 초기 설정·배포 방법은 실제 기능 구현 시 추가합니다.
